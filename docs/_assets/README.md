# Локальные файлы Docsify

Используется Docsify `4.13.1`:

- `docsify.min.js` — основной runtime;
- `search.min.js` — официальный плагин полнотекстового поиска;
- `vue.css` — стандартная тема;
- `swpro-docs.css` — оформление SWPro.

Исходный проект: https://github.com/docsifyjs/docsify

Docsify распространяется по лицензии MIT. Файлы сохранены локально, чтобы рабочая справка не зависела от доступности CDN.
