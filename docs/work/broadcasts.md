# Рассылки и безопасность аудитории

Для кого: суперадминистратор, лидер и консультант.

Клиентская рассылка отправляется только при действующем согласии на информационные и рекламные сообщения.

- Консультант отправляет только своим клиентам.
- Лидер работает только со своими клиентами, консультантами и лидерами своей ветки.
- Чужие клиенты и сотрудники не должны появляться в списках выбора.
- Поддерживаются текст, изображение, MP4 и кнопка-ссылка.
- Для VK используется только сообщество, которому конкретный клиент разрешил сообщения.
