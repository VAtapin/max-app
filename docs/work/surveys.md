# Опросы и результаты

Для кого: все роли.

Опросы SWPro описывают субъективные ощущения и предпочтения пользователя и формируют информационный результат.

- Прогресс сохраняется после каждого ответа.
- Незавершённый опрос можно продолжить.
- Завершённый результат можно посмотреть или пройти опрос заново.
- Результат видят клиент, закреплённый специалист и разрешённое руководство команды.

Повторное прохождение может показывать изменение баллов одинаковых шкал. Это сравнение ответов, а не медицинское улучшение или ухудшение.
