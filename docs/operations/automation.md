# Автоматические задачи

Для кого: суперадминистратор.

На сервере работают четыре независимые задачи:

| Задача | Периодичность | Назначение |
|---|---:|---|
| Рассылки | каждые 5 минут | Отправка запланированных рассылок |
| Автоматические сценарии | каждые 15 минут | Напоминания и действия по активности |
| Биллинг | ежедневно | Счета и проверка сроков оплаты |
| Очистка web-клиентов | ежедневно | Удаление брошенных временных профилей |

Эти задачи не дублируют друг друга. Повторный запуск миграций также безопасен: уже применённые файлы не выполняются снова.
