# Двухфакторная защита

Для кого: все рабочие роли.

Для 2FA нужно приложение с поддержкой TOTP: Яндекс ID, 2FAS, Aegis, Microsoft Authenticator или аналог.

1. Сначала установите приложение-аутентификатор.
2. Внутри приложения выберите добавление аккаунта по QR-коду.
3. Сканируйте QR-код именно приложением, а не обычной камерой или поиском Google/Яндекса.
4. Сохраните аккаунт и подтвердите одноразовый код в SWPro.

Если доступ потерян, суперадминистратор может отключить 2FA внутри формы учётной записи. Быстрой кнопки в общей таблице нет, чтобы защиту не отключили случайно.
