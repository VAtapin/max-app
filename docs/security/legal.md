# Юридические документы и персональные данные

Для кого: все роли.

Оператор персональных данных внутри SWPro — ИП, владелец платформы. Лидеры и консультанты получают только необходимый доступ к своим клиентам.

В сервисе используются:

- политика обработки персональных данных;
- согласие на обработку персональных данных;
- отдельное согласие на обработку ответов опросов;
- согласие на информационные и рекламные сообщения;
- пользовательское соглашение;
- публичная оферта на доступ к SWPro.

Реквизиты оператора задаются в разделе «Реквизиты документов». Пустые служебные переменные не публикуются. При изменении версии обязательного документа согласие запрашивается повторно. Основные базы данных находятся на территории России.
