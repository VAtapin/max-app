# Разрешение сообщений VK

Для кого: все роли.

Согласие на рассылку и техническое разрешение VK — разные действия. Для рекламной рассылки через VK нужны оба.

## В VK Mini App

После выбора «Хочу получать полезные материалы, акции и новости» открывается системное окно VK. Пользователь нажимает «Разрешить».

## В обычном браузере

Открывается официальное окно поверх страницы SWPro с web-виджетом VK. Если пользователь ещё не вошёл в VK, ему сначала предложат авторизоваться. Поэтому сообщение «VK доступен только внутри приложения» неверно.

Если у консультанта подключены и VK, и OK, на обычном мини-сайте показываются **оба** независимых блока: VK с официальным окном разрешения и OK с кнопкой открытия диалога группы. Внутри VK Mini App показывается только VK, а внутри OK Mini App — только OK.

Разрешение хранится для конкретного клиента и конкретного сообщества. При смене сообщества его нужно получить заново. Кнопка **«Проверить статус»** сверяет разрешение напрямую с VK методом `messages.isMessagesFromGroupAllowed`; Callback-события `message_allow` и `message_deny` только дополнительно синхронизируют локальную запись.

Если VK разрешает сообщения, но пользователь нажал **«Отключить в SWPro»**, в VK разрешение не меняется: SWPro лишь перестаёт отправлять сообщения. В блоке появится отдельная кнопка **«Включить в SWPro»**.

Если VK использовать не получается, клиент может указать email для материалов и уведомлений.
