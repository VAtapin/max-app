# Разрешение сообщений VK

Для кого: все роли.

Согласие на рассылку и техническое разрешение VK — разные действия. Для рекламной рассылки через VK нужны оба.

## В VK Mini App

После выбора «Хочу получать полезные материалы, акции и новости» открывается системное окно VK. Пользователь нажимает «Разрешить».

## В обычном браузере

Открывается web-виджет VK. Если пользователь ещё не вошёл в VK, ему сначала предложат авторизоваться. Поэтому сообщение «VK доступен только внутри приложения» неверно.

Разрешение хранится для конкретного клиента и конкретного сообщества. При смене сообщества его нужно получить заново. События `message_allow` и `message_deny` подтверждают разрешение или отказ.

Если VK использовать не получается, клиент может указать email для материалов и уведомлений.
