# Подключение группы OK

Для кого: суперадминистратор, лидер и консультант.

Для OK используется Bot API группы.

1. В desktop-версии OK откройте настройки сообщений группы.
2. Разрешите сообщения для нужной аудитории.
3. Получите или сгенерируйте ключ доступа Bot API.
4. Скопируйте ID группы из адреса `ok.ru/group/...`.
5. В SWPro создайте подключение OK и укажите название, ID группы и токен.

Пользователь должен разрешить группе отправлять ему сообщения. Если доставка не работает, проверьте статус группы и не был ли отозван токен.
