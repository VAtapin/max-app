# Подключение сообщества VK

Для кого: суперадминистратор, лидер и консультант.

Подключение нужно, чтобы SWPro принимал сообщения из VK и отправлял ответы клиентам от имени сообщества.

> Не публикуйте ключ доступа и секретный ключ. Если их увидел посторонний, удалите ключ в VK и создайте новый.

## 1. Откройте управление сообществом

Зайдите в сообщество и нажмите «Управление».

![Управление сообществом](https://swpro.ru/admin/uploads/help/vk-community-page-marked.png)

## 2. Включите сообщения

Откройте «Сообщения», включите сообщения сообщества и сохраните приветствие.

Рекомендуемый текст:

> Здравствуйте! Здесь можно пройти чек-ап и получить ответ консультанта. Нажмите «Начать» или откройте приложение SWPro.

![Настройки сообщений](https://swpro.ru/admin/uploads/help/vk-messages-marked.png)

## 3. Включите возможности бота

В разделе «Настройки для бота» включите возможности ботов и кнопку «Начать».

![Настройки бота](https://swpro.ru/admin/uploads/help/vk-bot-settings-marked.png)

## 4. Создайте ключ доступа

Откройте «Дополнительно → Работа с API → Ключи доступа». Создайте ключ с правом на сообщения сообщества. Скопируйте его в поле «Ключ доступа» SWPro.

![Ключ доступа VK](https://swpro.ru/admin/uploads/help/vk-api-access-token-marked.jpg)

## 5. Настройте Callback API

Адрес сервера:

```text
https://swpro.ru/api/vk_callback.php
```

Версия API: `5.199`.

Из блока подтверждения перенесите в SWPro число `group_id` и строку, которую должен вернуть сервер.

![group_id](https://swpro.ru/admin/uploads/help/vk-callback-group-id-marked.png)

![Строка подтверждения](https://swpro.ru/admin/uploads/help/vk-callback-confirmation-marked.png)

## 6. Укажите секретный ключ

SWPro создаёт секретный ключ подключения автоматически. Скопируйте его из SWPro в одноимённое поле VK и сохраните.

![Секретный ключ](https://swpro.ru/admin/uploads/help/vk-callback-secret-marked.png)

## 7. Включите события

Отметьте входящее сообщение, действие с сообщением, разрешение на получение, запрет на получение и прочитанность сообщений.

![События Callback API](https://swpro.ru/admin/uploads/help/vk-callback-events-marked.png)

После первого корректного Callback-события подключение считается проверенным.

## Как выбирается сообщество

Сначала используется готовое подключение консультанта, затем его лидера. Если их нет — активное стандартное сообщество, назначенное суперадминистратором. Один `group_id` нельзя добавить повторно.
