# Справочный центр SWPro

Здесь собраны инструкции по работе с версией 1 платформы SWPro.

## Что можно найти

- первый вход и заполнение анкеты клиента;
- роли лидера, консультанта и суперадминистратора;
- web-клиенты, объединение аккаунтов и реферальные ссылки;
- мини-сайты, шаблоны и наследование контента;
- опросы, результаты, обращения и рассылки;
- подключение сообщений VK и OK;
- подписки, рабочие места и способы оплаты;
- юридические документы, персональные данные и 2FA;
- автоматические задачи сервера.

> SWPro предоставляет информационный сервис. Опросы не являются медицинским обследованием, диагнозом или назначением лечения.

Начните с раздела [О SWPro](/start/overview.md).
