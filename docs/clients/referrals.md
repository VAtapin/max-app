# Реферальные ссылки и коды

Для кого: суперадминистратор, лидер и консультант.

Коды лидеров, консультантов и администраторов уникальны во всей системе.

- Новая ссылка может изменить выбранного специалиста только до завершения анкеты.
- После подтверждения клиента другая ссылка не меняет его закрепление молча.
- При изменении кода старая ссылка продолжает работать через сохранённый псевдоним.
- Смена кода не удаляет клиентов, историю и платформенные связи.
- Система не сохранит код, совпадающий с действующим или старым кодом другого пользователя.
