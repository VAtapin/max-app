# Перевод клиента в лидера или консультанта

Для кого: суперадминистратор и лидер.

Клиента можно связать с существующим рабочим аккаунтом или создать для него новое рабочее место.

1. Найдите клиента и откройте настройку преобразования.
2. Проверьте найденные похожие рабочие аккаунты.
3. Если нужный аккаунт уже существует, используйте «Связать с существующим».
4. Если его нет, выберите роль, руководителя и создайте рабочий аккаунт.

ID клиента, лидера и пользователя админки могут отличаться, потому что это разные таблицы. Связь хранится явно, поэтому VK, Telegram, web-профиль и история не должны потеряться.
