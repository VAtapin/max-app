# Web-клиенты и объединение аккаунтов

Для кого: суперадминистратор, лидер и консультант.

Обычный браузер сначала получает временный web-профиль. Это случайный технический идентификатор, а не ID лидера или консультанта.

- Без принятого соглашения временный профиль удаляется через 3 дня.
- После принятия соглашения на объединение с VK, Telegram, MAX или другой подтверждённой платформой даётся 5 дней.
- До завершения анкеты другая реферальная ссылка может изменить выбранного специалиста.
- После объединения профиль, платформы и история остаются у одного клиента.

## Объединение похожих профилей

Похожие профили не объединяются только из-за совпадения имени. Пользователь подтверждает связь аккаунтов либо администратор выполняет проверенное объединение. Перед действием сверяются имя, город, возраст и принадлежность платформ.
