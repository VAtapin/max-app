# Контроль базы ИИ

Для кого: суперадминистратор.

Раздел «Контроль базы ИИ» объединяет техническую подготовку материалов для помощника. Он показывает, сколько продуктов и диапазонов чек-апа утверждено, сколько страниц Docsify синхронизировано, а также количество активных правил и сценариев.

## Синхронизация Docsify

HELP ведётся только в Markdown внутри `docs/`. Обычный серверный deploy синхронизирует справку автоматически. Кнопка «Синхронизировать Docsify» позволяет выполнить обновление повторно из админки. Система обновит поисковую копию для ИИ, а удалённые страницы отключит. Редактировать одну инструкцию одновременно в Docsify и старом разделе HELP не требуется.

По умолчанию страница доступна только помощнику админки. В начало Markdown можно добавить метаданные:

```text
---
ai_audience: admin
ai_keywords: продукты карточка состав
ai_page_context: crud.php?module=products
ai_enabled: true
---
```

Для клиентских материалов используйте `ai_audience: client` или `both` только после проверки содержания.

## Допуск продукта или результата

Материал используется клиентским ИИ только когда одновременно включён флаг «Разрешить ИИ» и установлен статус «Утверждено». До этого карточка остаётся доступной в обычном интерфейсе, но не попадает в ответы помощника.

Для продукта необходимо проверить состав, применение, предупреждения, противопоказания, допустимые формулировки и первоисточники. Для диапазона чек-апа — объяснение, совет, исключения, условия передачи человеку и первоисточники.

## Связи и исключения

Правило связывает один диапазон результата с продуктом или опубликованным материалом. Действие «Исключить» имеет приоритет над рекомендацией того же объекта. Клиент увидит только активные и утверждённые правила.

## Сценарии

Сценарий выбирается по событию и каналу. Разрешены переменные `{{first_name}}`, `{{consultant_name}}`, `{{test_title}}`, `{{days}}` и `{{city}}`. Если подходящего утверждённого сценария нет, SWPro использует безопасный стандартный текст.

## Хранение и видео

Сроки хранения задаются в «Настройки ИИ». Ежедневная серверная задача удаляет устаревшие диалоги, архивные черновики, ошибочные задания и детальную статистику. Правила доставки видео задаются отдельно для Telegram, VK, MAX, OK и Web; значения нужно сверить с актуальными ограничениями API выбранного канала.

Все существующие и новые результаты обычных и многошкальных тестов автоматически получают разрешение на подготовку для ИИ. Новый или изменённый результат остаётся на проверке, пока у него нет подтверждённого источника: система не подменяет источник выдуманной ссылкой. После утверждения ИИ использует последние результаты каждого пройденного клиентом теста, а не только одного заранее заданного чек-апа.

Стандартные сценарии приветствия, завершения теста, повторного теста, возвращения после перерыва, завершения плана и дня рождения создаются автоматически. Их можно заменить более приоритетными сценариями владельца.
