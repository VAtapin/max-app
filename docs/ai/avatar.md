# Подключение AI-аватара

Видеоаватар SWPro работает через одного из двух внешних провайдеров: **HeyGen** или **Tavus**. OpenAI в этой функции может подготовить сценарий и голос, но готовое видео с говорящим аватаром создаёт выбранный видеопровайдер.

Секретный API-ключ нельзя вводить на странице аватара и нельзя передавать лидерам или консультантам. Он хранится только на сервере в едином конфигурационном файле `deploy/plesk/live.env`.

## Что нужно подготовить

Для подключения понадобятся:

1. аккаунт HeyGen или Tavus с доступом к API и достаточным балансом;
2. секретный API-ключ провайдера;
3. созданный в кабинете провайдера аватар;
4. ID аватара, а для HeyGen также ID голоса;
5. разрешённая в тарифе функция обычного или персонального AI-видео.

Достаточно подключить **одного** провайдера. Одновременно настраивать HeyGen и Tavus необязательно.

## Вариант 1. HeyGen

1. Войдите в кабинет HeyGen.
2. Откройте **Settings → API → API token**.
3. Создайте или перевыпустите ключ и сразу сохраните его в безопасном месте. После создания HeyGen может больше не показывать ключ целиком.
4. Создайте или выберите аватар и голос в HeyGen.
5. Сохраните значения `avatar_id` и `voice_id` — они понадобятся на странице «Мой AI-аватар» или «Системный AI-аватар».

Официальная информация: [ключ и тариф API HeyGen](https://help.heygen.com/en/articles/10060327-heygen-api-pricing-explained), [API HeyGen](https://docs.heygen.com/reference).

Добавьте на сервере строку:

```env
HEYGEN_API_KEY=ваш_секретный_ключ
```

## Вариант 2. Tavus

1. Войдите в Tavus Developer Portal.
2. Откройте раздел **API Key**.
3. Нажмите **Create New Key**, задайте название и при необходимости ограничьте разрешённые IP-адреса.
4. Скопируйте ключ и сохраните его в безопасном месте.
5. Создайте или выберите Replica и сохраните её `replica_id`. В SWPro это значение вводится в поле «ID аватара».

Официальная информация: [аутентификация Tavus](https://docs.tavus.io/api-reference/authentication), [создание видео Tavus](https://docs.tavus.io/api-reference/video-request/create-video).

Добавьте на сервере строку:

```env
TAVUS_API_KEY=ваш_секретный_ключ
```

## Куда добавить ключ на сервере

Откройте единый конфигурационный файл:

```bash
cd /var/www/vhosts/swpro.ru/httpdocs
nano deploy/plesk/live.env
```

Добавьте **одну** из переменных `HEYGEN_API_KEY` или `TAVUS_API_KEY`, сохраните файл и выполните обычное развёртывание:

```bash
bash deploy/plesk/deploy.sh deploy/plesk/live.env
```

Не добавляйте ключ в PHP-файлы, базу данных, JavaScript, README, сообщения или скриншоты. Не отправляйте его лидерам и консультантам.

## Что выбрать в SWPro

1. Войдите как суперадминистратор.
2. Откройте **Настройки → Настройки ИИ**.
3. В поле «Видеоаватары» выберите тот же провайдер: HeyGen или Tavus.
4. Убедитесь, что рядом написано «ключ найден», и сохраните настройки.
5. Откройте **Работа → Системный AI-аватар** либо попросите лидера открыть «Мой AI-аватар».
6. Укажите `avatar_id` для HeyGen или `replica_id` для Tavus. Для HeyGen дополнительно укажите `voice_id`.

Загруженные в SWPro фотография и исходное видео хранятся закрыто, но сами по себе не создают внешний аватар автоматически. Сначала цифровой аватар или Replica создаётся и подтверждается в кабинете выбранного провайдера, после чего её ID связывается со SWPro.

## Как проверить работу

1. В AI-студии создайте сценарий видео.
2. Проверьте и сохраните текст.
3. Подтвердите отправку сценария видеопровайдеру.
4. SWPro создаст задание, а `admin/cron/run-automations.php` будет проверять его состояние.
5. После завершения MP4 сохранится в закрытом хранилище SWPro и станет доступен владельцу рабочего места.

Если отображается «ключ не найден», проверьте название переменной, отсутствие пробелов вокруг `=`, правильность файла `deploy/plesk/live.env` и повторно запустите развёртывание. Если провайдер отклоняет запрос, проверьте баланс API, действительность ключа, `avatar_id`/`replica_id` и `voice_id`.
