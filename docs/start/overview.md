# О SWPro

Для кого: все роли.

SWPro объединяет персональные мини-сайты, информационные опросы, клиентскую базу, обращения, рассылки, команду и оплату рабочих мест.

Платформа помогает вести клиента, но не заменяет личную работу специалиста. Каждый пользователь видит только разрешённую ему область данных.

## Важно об опросах

Опросы собирают субъективные ощущения и предпочтения. Они не являются медицинским обследованием, диагнозом, заключением или назначением лечения.

## Персональные данные

Внутри SWPro один оператор персональных данных — ИП, владелец платформы. Лидеры и консультанты получают ограниченный доступ к данным своих клиентов, но не становятся отдельными операторами только из-за реферальной ссылки.
