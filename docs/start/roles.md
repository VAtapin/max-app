# Роли и доступ

Для кого: все роли.

## Суперадминистратор

Управляет всей платформой: лидерами, консультантами, пользователями админки, глобальными тарифами, бухгалтерией, способами оплаты, документами, общим контентом, шаблонами, подключениями и настройками.

## Лидер

Управляет своей веткой, дочерними лидерами, консультантами, клиентами и командным контентом. Видит только свою структуру. Может создавать тарифы для нижестоящей ветки в пределах лимитов собственной подписки.

## Консультант

Работает только со своими клиентами, обращениями, результатами, контентом и рассылками. Не видит чужих лидеров, консультантов и общесистемную клиентскую базу.

## Клиент

Заполняет анкету, проходит информационные опросы, читает материалы и связывается с закреплённым специалистом через Mini App или web-страницу.
