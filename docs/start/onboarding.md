# Первый вход клиента

Для кого: лидер и консультант.

При первом входе клиент принимает обязательные документы и заполняет анкету.

## Обязательные поля

- имя и фамилия;
- пол;
- возраст или дата рождения;
- город.

Телефон и email можно оставить пустыми. Их стоит указать, если клиент хочет получать уведомления через эти каналы.
