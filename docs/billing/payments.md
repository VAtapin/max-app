# Оплата

Для кого: все рабочие роли.

В разделе «Моя подписка» показаны тариф, оплаченный период, состояние счёта и доступные лимиты. Кнопка «Оплатить» открывает доступные способы.

Суперадминистратор настраивает методы в разделе «Подписка → Методы оплаты»:

- Stripe;
- PayPal;
- ЮKassa;
- CloudPayments;
- перевод по реквизитам или другой ручной способ.

Все активные способы показываются без автоматического выбора страны. Ручной перевод подтверждает администратор; онлайн-платёж подтверждается webhook платёжного сервиса.
