# Шаблоны и наследование контента

Для кого: суперадминистратор, лидер и консультант.

Контент наследуется по уровням: общий SWPro → командный лидера → личный консультанта.

- Изменение общего объекта создаёт версию владельца и не портит оригинал.
- Личная версия консультанта имеет приоритет над командной версией.
- Скрытие объекта одним владельцем не удаляет его у остальных.
- Шаблон заполняет мини-сайт стартовыми значениями.
- Сброс к родительскому варианту заменяет личные настройки актуальным шаблоном.
