# Настройка мини-сайта

Для кого: лидер и консультант.

Мини-сайт — персональная страница специалиста. Пустые необязательные блоки можно не заполнять.

Настройте фотографию, описание, контакты, материалы, продукты, опросы, акции, программы и марафоны.

Суперадминистратор и лидер могут переключаться между доступными профилями через выпадающий список. Если профиль не виден среди первых вариантов, используйте поле «Поиск профиля»: начните вводить имя или ID, выберите найденного человека и нажмите «Показать». Поиск выполняется на сервере и не загружает в страницу весь список команды.

## Кэшбэк и подарки

Можно добавить несколько карточек — на странице они показываются одна под другой. Для каждой карточки настраиваются:

- заголовок;
- описание;
- изображение;
- персональная ссылка;
- текст кнопки.

Текст кнопки по умолчанию: «Оформить карту клиента».
