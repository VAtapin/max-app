# Настройка мини-сайта

Для кого: лидер и консультант.

Мини-сайт — персональная страница специалиста. Пустые необязательные блоки можно не заполнять.

Настройте фотографию, описание, контакты, материалы, продукты, опросы, акции, программы и марафоны.

## Кэшбэк и подарки

Можно добавить несколько карточек — на странице они показываются одна под другой. Для каждой карточки настраиваются:

- заголовок;
- описание;
- изображение;
- персональная ссылка;
- текст кнопки.

Текст кнопки по умолчанию: «Оформить карту клиента».
